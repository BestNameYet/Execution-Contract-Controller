# Simplified Transaction Layer — Folder Manifest

This README is a manifest of the contents of `simplified-transaction-layer/`. It does not define transaction-layer requirements. Requirements are maintained separately so they can change without making this manifest an alternate specification.

## Manifest

| Path | Type | Purpose |
|---|---|---|
| `README.md` | Manifest | Identifies and describes the files and folders contained in this implementation surface. |
| `requirements/` | Directory | Contains the current requirements and implementation-evidence tracking for the simplified transaction layer. |
| `requirements/REQUIREMENTS.md` | Requirements table | Maintains requirement IDs, requirement text, status, and exact script/line evidence showing where each requirement is met. |

## Manifest maintenance

Update this manifest when files or directories are added, removed, renamed, or their repository role changes. Do not duplicate the transaction-layer requirements here.
